- 모든 계산기 페이지의 상단 메뉴를 최신 20개 계산기 메뉴로 통일
- 기존 법률/부동산/직장인 계산기 페이지에서 금융 계산기 버튼이 사라지는 문제 수정
- 현재 페이지 버튼 active 표시 유지
- 기존 계산 기능, sitemap.xml, robots.txt, 개인정보처리방침, 이용약관, 문의 페이지 유지
